# 表情筋チェックAI

ブラウザだけで完結する、表情筋セルフチェックツール。写真や動画を**どこにも送信せず**、すべて端末内で顔のランドマークを解析し、目の開き・左右差・口角の高さ・笑顔のタイプを数値で見える化します。

顎・舌・首の脱力をベースにした表情筋の取り組みを、客観的にモニタリングすることを目的にしています。

## できること

- **カメラ / 写真** の2モードで顔を解析（リアルタイム）
- **目の開き**（左右別・左右差%）
- **口角の高さ**（左右別・左右差）
- **顔の左右対称スコア**（0〜100）
- **笑顔のタイプ判定** — 「横に引く笑顔（笑筋・代償）」より「斜め上に上げる笑顔（大頬骨筋・インナー主導）」を推奨。それぞれを別スコアで表示
- **目視チェック欄** — 首の縦スジ・口角横の溝など、AIでは測りにくい項目を自分で記録
- **記録** — 計測結果を端末内（localStorage）に保存し、推移を確認

## 技術

- [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker)（Google）をブラウザ内（WASM）で実行
- サーバー不要・ビルド不要の静的サイト。画像データは端末外に出ません

## 使い方（ローカル）

カメラを使うには `https` もしくは `localhost` が必要です。

```bash
# どれか一つ
python3 -m http.server 8000
# → http://localhost:8000 を開く
```
